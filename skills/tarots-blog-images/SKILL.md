# TAROTS chat blog images

The blog's first articles all got the same kind of picture: tarot cards laid out on a table. It is repetitive and
says nothing about the article. This skill gives every article **its own** picture — a scene, a place, a person, a
season, an object or a metaphor from what the article is actually about — and replaces cover and inline pictures
through the REST API, without touching the text, the SEO fields or the status.

Works for any agent that can run a shell command (Hermes, OpenClaw, Codex, Claude Code). Python 3.8+, standard
library only; pictures come from the separate **`litmedia-skill`** (its own login and credits: read its `SKILL.md`
once). The script is `scripts/tarots_images.py` (paths below are relative to this skill).

## Setup (once)

1. An admin creates a key in the console: **Blog → Keys**, permission **«Cambiare le immagini» (`blog:media`)**.
   That permission touches only pictures, but on **every** article: keep the key for this job alone.
2. For the first run only:
   ```
   TAROTS_API_URL=https://tarots.chat/api
   TAROTS_MEDIA_KEY=tk_live_…
   ```
   The key is then remembered in `~/.tarots-blog/media-credentials.json` (outside any repository). Never put it in a
   file of a project, a prompt or a message; only its 12-character prefix may appear in output.
3. Check: `python scripts/tarots_images.py list` and `python scripts/tarots_images.py balance`.

## Workflow

### 1. Decide the scope with the operator
- Which articles: all, only published, one language, or the ids the operator names. `list --todo` shows what this
  tool has not redone yet (the local record is `~/.tarots-blog/images-progress.json`).
- Cover only, or cover **and** pictures in the text (the operator's standing choice for this blog: both).
- **Budget**: each picture costs **10 credits** (Seedream 5.0, 2K; there is no 1K). Tell the operator:
  *N articles × (1 cover + k inline) × 10 = total*, and the current `balance`. Get a yes before spending. If the
  operator already set a budget, keep to it with `--budget` (credits still allowed) and `--reserve` (credits that
  must stay on the account).

### 2. For each article: read before you imagine
```
python scripts/tarots_images.py show <id>
```
Read title, subtitle, keyword, section, tags and **the whole text**. Find what the article is really about: the
card's image and symbols, the human situation it speaks to (grief, a new love, a decision, a change of season),
the place or the time. Note where the text already has pictures (`immagini_nel_testo`, numbered from 0) and what
their alt text says.

### 3. Write the prompts (the heart of the job)
Follow `references/prompts.md`. In short:
- **Never** the tarot spread on a table, cards face down, a fan of cards, a reading table. The script refuses
  these prompts. At most **one** card may appear, as a small detail inside a larger scene.
- One clear idea per picture, taken from **this** article: a scene, a landscape, a person seen from behind or at a
  distance (never a recognisable real person), a season, an object charged with meaning, a visual metaphor.
- Vary across the batch: keep a running list of the subjects already used (`progress` shows the prompts) and do
  not repeat a subject, a setting or a composition within the same run.
- One house style for all of them, so the blog looks like one magazine: the site's palette (warm paper, deep plum,
  brass gold, verdigris), painterly editorial illustration, soft natural light — see the reference for the exact
  style line to append.
- Always end with: `no text, no letters, no numbers, no watermark, no logo`.
- Covers are **3:2**; pictures in the text **4:3** (or 1:1 for a symbol close-up).

### 4. Try it dry first
```
python scripts/tarots_images.py generate --prompt "<prompt>" --out work/<slug>-cover.jpg --dry-run
python scripts/tarots_images.py cover <id> work/<slug>-cover.jpg --alt "<alt>" --dry-run
```
For the first run with an operator, show the prompts for **three** articles and wait for an ok before generating.

### 5. Generate and swap
```
python scripts/tarots_images.py generate --prompt "<prompt>" --out work/<slug>-cover.jpg --budget <left>
python scripts/tarots_images.py cover <id> work/<slug>-cover.jpg --alt "<what the picture shows>"

python scripts/tarots_images.py generate --prompt "<prompt>" --aspect 4:3 --out work/<slug>-1.jpg --budget <left>
python scripts/tarots_images.py inline <id> --replace 0 work/<slug>-1.jpg "<alt>"
```
- **Look at every picture before swapping it in** (open the file). Reject and regenerate (once) if it shows a card
  spread anyway, text or letters, a malformed hand or face, or has nothing to do with the article.
- `inline` also takes `--add <after paragraph> <file> <alt>` (0 = after the first paragraph; paragraphs are blocks
  separated by a blank line) and `--remove <n>`. Add a picture only where it serves the text, not at the top (that is
  the cover) and not after the last paragraph. One or two per article is plenty.
- Alt text: describe what is **in the new picture**, 8–125 characters, the keyword only if it fits naturally.
- The server makes the list thumbnail of every uploaded picture by itself: nothing to do.
- A timeout from LitMedia: run `balance` and check the article with `show` before trying again. Never resubmit in a
  loop. `429` from the API: stop and wait.

### 6. Report
A short table: article, what changed (cover / inline n), the subject of each picture, credits spent, balance left,
and anything the operator should look at (a picture you rejected, an article whose text made a good picture hard).

## Hard rules
- Only pictures: never try to change text, title, SEO fields or status (the key cannot, and should not try).
- No card spreads on tables. No text in pictures. No recognisable real people, no fake photos of real events, no
  copy of the Thoth deck's actual artwork (copyrighted): symbolic, atmospheric scenes are right.
- Spend only the credits the operator agreed to. Check `balance` when in doubt.
- Never disable TLS verification, never follow a redirect with the key, never send the key anywhere but
  `TAROTS_API_URL`, never send it to LitMedia.

## Files
- `scripts/tarots_images.py`: the CLI (`-h` on every command).
- `references/prompts.md`: how to find the subject, the house style, examples by kind of article, what to avoid.
- `references/api.md`: the four endpoints, if you would rather call them directly.
